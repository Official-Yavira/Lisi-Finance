# Lisi Finance

Sito vetrina multilingue per il progetto Lisi Finance.

- Lingue: italiano, tedesco, inglese
- Mercato iniziale: Ticino, con prospettiva nazionale svizzera
- Identità: blu notte, avorio e oro champagne

## Anteprima locale
Aprire `index.html` in un browser.

## Pubblicazione
Il repository può essere pubblicato con GitHub Pages da **Settings → Pages**, selezionando il branch `main` e la cartella `/ (root)`.

## Nota
Lisi Finance è presentato come progetto in fase di sviluppo. I servizi descritti sono aree di interesse future e non costituiscono un'offerta professionale attiva. Prima della pubblicazione, sostituire i recapiti dimostrativi e verificare i requisiti legali e professionali applicabili.
